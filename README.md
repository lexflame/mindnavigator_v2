# MindNavigator v2 (build: 12.02.2026)

[![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)](https://www.python.org/)

[![Storage](https://img.shields.io/badge/Storage-SQLite_WAL-4c566a)](#локальная-база-данных)

**MindNavigator** — настольный центр управления задачами, проектами, картами, заметками, файлами, объектами и покупками в одном интерфейсе. Использует локальную SQLite-базу, кастомный заголовок окна, левый rail режимов и быстрый поиск по сущностям.

## Ключевые возможности

- **Frameless UI**: собственный `TitleBar`, ресайз по краям, snap, `F11` для полноэкранного режима.
- **Tray-режим**: сворачивание в трей и быстрое восстановление.
- **Быстрый поиск** по задачам, проектам, картам/меткам, заметкам, файлам, объектам.
- **Единая база данных**: SQLite (WAL), авто-инициализация схемы, лёгкие миграции, демо-данные при пустой базе.

## Рабочие пространства

### Задачи
- Быстрое создание (дата, время, приоритет).
- Вкладки/фильтры по статусу и срокам.
- Привязки: заметки, объекты, карты, метки, файлы.

### Проекты
- Список проектов с областями (area), статусом и приоритетами.
- Фильтрация задач по проекту через навигацию.

### Карты
- Создание карт с тайлами (W/H) и каталогом тайлов.
- Режим просмотра/редактирования с метками.
- Метки редактируются в отдельном диалоге.
- Правая панель «Данные объекта» с изменяемой шириной.

### Заметки
- Теги, привязки к проектам, избранное и блокировка.

### Файлы
- Работа с «облачной» папкой на диске.
- Индексация файлов, метаданные, предпросмотр.

### Объекты
- Каталог объектов (title, catalog, type, status, description).
- Привязки к задачам/меткам.
- Извлечение текста из документов (`.txt`, `.docx`, `.doc`).

### Покупки
- Таблица товаров, карточка товара, источники (URL), история цен.
- Парсинг товаров из интернет-магазинов через адаптеры.
- Сравнение товаров по нормализованным свойствам.
- Хотелки (wishlist), цель по цене, приоритет, количество.

### Коллекции
- Дерево категорий коллекций.
- Импорт коллекции из папки, создание элементов коллекции.
- Повторный импорт/синхронизация, пометка отсутствующих файлов.
- Превью изображений/видео/документов, навигация по элементам.

## Локальная база данных

- SQLite-файл создаётся автоматически.
- Путь по умолчанию: `~/.mindnavigator/mindnavigator.db`
- Включены `WAL`, `foreign_keys=ON`, индексы по ключевым полям.
- При пустой базе добавляются демо-данные.

## Установка и запуск

### Требования

- Python 3.10+
- PySide6
- qtawesome

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск

```bash
python main.py
```

## Сборка Windows (PyInstaller)

Готовый spec-файл: `pyinstaller.spec`

```bash
pyinstaller pyinstaller.spec
```

- Иконка: `assets/icon.ico`
- В сборку включается каталог `assets/`

## Структура проекта

- `main.py` — точка входа, сплэш-экран, стили, запуск главного окна.
- `mindnavigator/main_window.py` — каркас приложения, режимы, трей, хоткеи.
- `mindnavigator/storage.py` — SQLite-хранилище, dataclass-сущности, миграции.
- `mindnavigator/ui/` — общие виджеты (`TitleBar`, rail, поиск).
- `mindnavigator/ui/dialogs/` — диалоги и формы.
- `mindnavigator/workspaces/` — рабочие пространства (tasks/projects/maps/notes/files/objects/purchases/collections).
- `assets/` — ресурсы приложения.

## Полезно для разработки

- Сброс демо-данных: удалить `~/.mindnavigator/mindnavigator.db`.
- Глобальные стили: `mindnavigator/ui/styles.py`.
