## Title
Add Ctrl multi-select and a fixed bottom batch-actions bar for the Tasks list.

## Scope
- Enable standard multi-selection in the Tasks list so the user can keep selecting tasks with `Ctrl`.
- Show a fixed bottom batch-actions panel over the list when two or more tasks are selected.
- Provide grouped actions for complete, delete, move to tomorrow, priority up/down, move to date, move to project, marker color, marker theme, and defer.
- Keep the implementation scoped to Tasks list mode without breaking current BOARD, GANTT, DASH, sticky headers, or drag-drop behavior.
- Cover the selection and batch-action flow with focused workspace tests.
