# TASK_87B88003-41A0-4A20-B263-94F4313E67AA

## Title
Add the `Задача план` property and plan-item behavior for Tasks list, task editing, and drag-drop flows.

## Scope
- Add a persistent `Задача план` flag for tasks and expose it in the task edit dialog next to the project selector.
- Treat every descendant of a plan task as a plan item with inherited behavior instead of a separate manually assigned mode.
- Remove priority and overdue semantics from plan items while keeping their completion state and hierarchy visible.
- Add stable numbering for plan items within their direct parent and keep this numbering updated after drag-drop reordering.
- Restrict drag-drop for plan items to reordering inside the same parent branch and prevent cross-parent or cross-day moves.
- Keep completed plan items visible in the list until their parent task is completed.
- Cover storage migration, model rules, delegate rendering, and edit dialog behavior with focused tests.

## Rollback
- Revert the new task schema columns and plan-specific model branches if the feature destabilizes regular tasks or existing subtask flows.
- Remove plan-item drag-drop restrictions separately if only reorder behavior regresses while keeping the persistence model intact.
- Keep numbering and priority suppression localized so they can be rolled back without undoing unrelated task rendering changes.

## Notes
- The root plan task keeps its normal task semantics; the special rules apply to descendants derived from that root flag.
- Plan-item behavior should be computed from ancestry in the model so nested descendants inherit the same restrictions automatically.
