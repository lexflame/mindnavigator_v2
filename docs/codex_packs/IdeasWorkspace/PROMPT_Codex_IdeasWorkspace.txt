ЗАДАЧА ДЛЯ CODEX
Сделай новый Workspace MindNavigator: «Идеи» (IdeasWorkspace) в стиле текущего тёмного dashboard UI проекта.

КАК РАБОТАЕТ
- Слева: список идей (карточки с заголовком, проектом, статусом, ⭐value 1..5 и ⚙effort 1..5).
- Справа: инспектор выбранной идеи с табами: «Содержание», «Связи», «Материалы», «Решение».
- Сверху: Search + кнопки: «+ Идея», «Импорт», «Разобрать инбокс», «В архив».

КЛЮЧЕВАЯ ЛОГИКА
- Поиск фильтрует по title+body.
- Контекстное меню по элементу списка: Edit, Archive/Unarchive, Delete (confirm), Transform → (Task/Note/Object/Marker).
- Transform создаёт сущность с project_id/title/body из идеи и сохраняет обратную ссылку (relation или source_idea_id).

РЕАЛИЗАЦИЯ
- Используй BaseWorkspace и текущие паттерны проекта (controller/repository, модели, сигналы, общий стиль).
- БД: можно применить миграцию из DB_migration_ideas.sql.
- Подробный пошаговый план и критерии приёмки см. SPEC_IdeasWorkspace_StepByStep.md.
