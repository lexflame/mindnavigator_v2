# API Notes: TASK_5A9E2C71-6D44-4B69-B193-0E4A3C1F2D88

## Title
Domain API for project tree operations.

## Implemented API
1. Tree fetch:
- `fetch_project_tree()` returns full project list ordered by `(parent_project_id, sort_order, id)`.
- `fetch_project_children(parent_project_id)` returns direct children of a parent in stable order.

2. Move/reparent/reorder:
- `move_project(project_id, new_parent_project_id, new_sort_order=None)`:
  - supports reparent and sibling reposition;
  - blocks self-parent and cyclic moves;
  - reindexes sibling groups after move.
- `reorder_project(project_id, new_sort_order)`:
  - reorders within current parent.

3. Internal helpers:
- `_reindex_project_group(parent_project_id)` ensures contiguous sibling `sort_order`.
- Reuses cycle checks and persisted `sort_order` model from storage task.

## Behavior Guarantees
1. Reparent move preserves data integrity and prevents cycles.
2. Sibling order stays deterministic after each move/reorder.
3. Out-of-range requested target position is clamped into valid range.
