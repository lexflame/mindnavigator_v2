# Hotfix Notes: TASK_04051FC3-09AF-4387-AA60-831861E32727

## Title
Startup DB migration fix for legacy databases without `projects.sort_order`.

## Problem
Application crashed at startup with:
- `sqlite3.OperationalError: no such column: sort_order`
- during `CREATE INDEX idx_projects_parent_order ... sort_order ...`

## Root Cause
In `Database._init_db()`, index creation on `projects(sort_order)` happened before migration step `_ensure_project_extended_columns()` that adds `sort_order` for old DBs.

## Fix
Added guard before creating `idx_projects_parent_order` in `_init_db()`:
- Read `PRAGMA table_info(projects)`.
- Create index only when `sort_order` already exists.
- Migration step still creates the column and the index afterward.

## Validation
1. `python -m compileall mindnavigator/storage.py` passed.
