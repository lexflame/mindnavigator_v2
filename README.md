# MindNavigator v2 (build: 19.01)

[![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![Qt](https://img.shields.io/badge/Qt-PySide6-41CD52?logo=qt&logoColor=white)](https://doc.qt.io/qtforpython/)
[![Storage](https://img.shields.io/badge/Storage-SQLite_WAL-4c566a)](#локальная-база-данных)

**MindNavigator** - настольный "пульт" для управления задачами, проектами, картами, заметками и файлами в одном интерфейсе. Приложение использует локальную SQLite-базу, кастомный заголовок окна и боковую навигацию, а также быстрый поиск по всем сущностям.

## Ключевые особенности

- **Кастомное окно без системного заголовка** (frameless): собственный `TitleBar`, ресайз по краям, прилипания к верхней границе (snap) и горячая клавиша `F11` для полноэкранного режима.
- **Сворачивание в трей** при минимизации: окно прячется, а из трея можно быстро восстановить.
- **Левый rail режимов**: Задачи, Проекты, Карты, Заметки, Файлы, Объекты, Настройки.
- **Колонка навигации** (проекты) + **панель быстрого поиска** по всем сущностям (задачи, проекты, карты/метки, заметки, файлы, объекты).
- **Единое хранилище данных**: SQLite (WAL), автоинициализация схемы, лёгкие миграции колонок, демо-данные при пустой базе.

## Рабочие пространства

### Задачи

- Быстрое создание задачи (дата, опциональное время, приоритет).
- Вкладки/фильтры (например, по дате и статусу выполнения).
- Привязка задачи к проекту.
- Редактирование задачи в диалоге.
- **Вложения к задаче**: можно привязывать заметки, объекты, карты, метки, файлы (через диалоги выбора).
- Просмотр привязанных изображений (превью-диалог) при настроенном облачном каталоге.

### Проекты

- Список проектов с областями (area), приоритетом и статусом архива.
- Фильтрация задач по выбранному проекту через навигационную колонку.

### Карты

- Создание карты с описанием, привязкой к проекту и параметрами тайлинга (W/H) и каталогом тайлов.
- Режим просмотра/редактирования карты с метками (метки редактируются отдельным диалогом).
- Полноэкранный режим карты управляется из главного окна (выход по `Esc`).

### Заметки

- Хранение заметок с тегами и привязкой к проекту.
- Флаги избранного и блокировки (locked).

### Файлы

- Работа с "облачным" каталогом на диске (путь задаётся в Настройках).
- **Сканирование и индексация**: подсчёт SHA-256, попытка извлечь hash из пути, проверка валидности, сохранение метаданных в БД.
- Превью изображений в отдельном диалоге.

### Объекты

- Каталог объектов (title, catalog, type, status, description).
- Работа с привязками к меткам/задачам.
- Поддержка извлечения текста из документов (`.txt`, `.docx`, `.doc`) без внешних зависимостей.

### Настройки

- Путь к облачному хранилищу (папка на ПК).
- **Резервное копирование**:
  - выбор папки бэкапов,
  - включение облачного каталога в архив,
  - автокопирование (daily/weekly/monthly),
  - лимит количества хранимых копий,
  - создание/восстановление/удаление бэкапа.

## Локальная база данных

- SQLite-файл создаётся автоматически.
- Путь по умолчанию: `~/.mindnavigator/mindnavigator.db`
- Включены `WAL`, `foreign_keys=ON`, индексы по ключевым полям.
- При пустой базе добавляются демо-данные (задачи, проекты, карты, заметки, объекты).

## Установка и запуск

### Требования

- Python 3.10+
- PySide6
- qtawesome

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск

```bash
python main.py
```

## Сборка Windows (PyInstaller)

В проекте есть готовый spec-файл: `pyinstaller.spec`.

```bash
pyinstaller pyinstaller.spec
```

- Иконка: `assets/icon.ico`
- В ресурсы сборки включается весь каталог `assets/`.

## Структура проекта

- `main.py` - входная точка, сплэш-экран, применение стилей, запуск главного окна.
- `mindnavigator/main_window.py` - каркас приложения, режимы, трей, хоткеи, полноэкран карты.
- `mindnavigator/storage.py` - SQLite-хранилище, датаклассы сущностей, инициализация схемы.
- `mindnavigator/ui/` - виджеты оболочки: `TitleBar`, левый rail, навигация по проектам, поиск.
- `mindnavigator/ui/dialogs/` - диалоги выбора сущностей и редактирования метки карты.
- `mindnavigator/workspaces/` - рабочие пространства (tasks/projects/maps/notes/files/objects/settings).
- `assets/` - `icon.ico`, `splash.jpg`.

## Полезно для разработки

- Сбросить всё и начать с демо-данных: удалить файл базы `~/.mindnavigator/mindnavigator.db`.
- Стили приложения находятся в `mindnavigator/ui/styles.py`.
