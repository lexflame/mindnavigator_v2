## 3. Список выработанных задач: Режим Задачи

### 3.01. `Задачи` :: `Форма СРП Задач` :: В верхний блок `Формы СРП Задач` слева от свойства Проект добавить свойство `Стадия` - значения получить из данных задачи из режиме `BOARD`->`Канбан` - свойство редактируемое в виде выпадающего списка.
### 3.02. `Задачи` :: `Форма СРП Задач` :: Внутри `Формы СРП Задач` перенместить блок `Родительская задача` и разместить над блоком `Дополнительно`, а так же внутри блока `Родительская задача` уменьшить шрифт.
### 3.03. `Задачи` :: `Форма СРП Задач` :: После выбора любого из свойств в `Форме СРП Задач` и после потери фокуса совершать сохранения свойства.
### 3.04. `Фикс` :: `Задачи` :: `Форма СРП Задач` :: Исправить ошибку по кнопке `Редактировать` в `Списке задач` вызвается старая форма редактирования задачи
### 3.05. `Задачи` :: `Список задач` :: По наведению на иконку `Листочка` в `Списке задач` влево выезжает кнопка `Изменить`, при этом она не должна смещать сосдение элементы списка задач, по наведению на `Листочик` он обрамлчется в белые границы. Кнопка `Изменить` должны быть визуально едина с выделенным после наведением иконкой `Листочка`.
### 3.06. `Задачи` :: `Список задач` :: Кнопку `Редактировать` в `Списке задач` переименовать в `Изменить`
### 3.07. `Фикс` :: `Задачи` :: `Список задач` :: Исправить ошибку по кнопку `+` в `Списке задач` вызывается форма создания после сохранения заголовка или любого другого параметра по клавише Enter появляется ошибка «Индификатор задачи должен быть положительным»
### 3.08. `Фикс` :: `Задачи` :: `Список задач` :: Исрпавить режим `Все` в режиме Задачи, в данном режиме скрывается переключатель дня, задачи перечислены все активные и отложенные, кроме выполненных, первичная сортировка по дате вторичная по приоритету, все вложенные задачи закреплены за родителями с указанием расхождения по датам с родительской задачей. 
### 3.09. `Задачи` :: `Список задач` :: В режиме `Задач` при переключении дня в `Списке задач` не изменять ширину области переключателя вне зависимости от длинны текста даты и названия дня в скобках.
### 3.10. `Задачи` :: `Список задач` :: В режиме Задачи меню `Фильтр` сделать в виде адекватного `Dropdown` -> `Bootstrap 4` так же визуально объеденить это меню с соседними элементами `Фильтр приоритета` и `Строка поиска`
### 3.11. `Задачи` :: `Список задач` :: Крестик справа от инпута `Строка поиска` в режиме `Задачи` визуально объеденить с инуптом `Строки поиска` но не переносить в область инпута а в виде отдлеьной кнопки визуально объединённой с инпутом. 
### 3.12. `Задачи` :: `Список задач` :: Сохранять фильтрацию установленную в панели `Haven` между запусками программы.
### 3.13. `Задачи` :: `Список задач` :: Реализовать слева от кнопки `Перенос на завтра` кнопку Play/Pause/Stop - (внутри обозначения в виде символов ei.play / ei.play / ei.pause )
#### play - запускает отсчёт времени для задачи как уже реализованно для план-задач и отрожать ход времени в `Списке задач`
#### pause - ставит учёт времени для задач на паузу
#### stop - останавливает учёт времени для задачи
#### работают вне зависимости от типа задачи

## 4. Список выработанных задач: Режим Проекты

### 4.01. `Проекты` :: `Форма СРП Проектов` :: В `Форме СРП Проектов` в свойстве `Область` давать возможность как вводить значение с клавиатуры как сейчас, так и выбирать из имеющихся по образу `Dropdown` -> `Bootstrap 4`
### 4.02. `Проекты` :: `Список проектов` :: В `Списке проектов` сделать визуальные маркеры в виде полос при наличии `Типов задач` для каждого из типов отдельная соответствующая цветовая полоса, по образу военных погон.
### 4.03. `Проекты` :: `Форма СРП Проектов` :: Красиво и адекватно отобразить список `Типов задач` в `Форма СРП Проектов`
### 4.04. `Проекты` :: `Форма СРП Проектов` :: Увеличить размер окна `Форма СРП Проектов`
### 4.05. `Проекты` :: `Форма СРП Проектов` :: Скомпановать элементы `Формы СРП Проектов` чтобы минимизировать необходимость вертикального скрола, при этом не меняя места размещения элементов, кнопки `+` в режиме редактирования можно перенести к списку свойств или инпута.
### 4.06. `Проекты` :: `Форма СРП Проектов` :: `Форма СРП Типов задач` :: При выборе цвета в `Форме СРП Типов задач` для других новых и действующих `Типов задач` исключать уже используемые цвета в рамках одного проекта из выпадающего меню при создании или редактирования `Типа задачи` 
### 4.07. `Проекты` :: `Форма СРП Проектов` :: `Форма СРП Типов задач` :: Для каждого из параметров `Типа задач` реализовать чекбокс `Задачи наследует свойство`, по-умолчанию неактивен, при активации выбранное свойство начинают наследовать задачи за которыми закреплён данный тип.
### 4.08. `Проекты` :: `Форма СРП Проектов` :: `Форма СРП Типов задач` :: Для каждого из параметров `Типа задач` после выбора любого из значений кроме None или Нет автоматически активируется чекбокс `Задачи наследует свойство`, значения None или Нет тоже могут наследоваться но только в случае если сам пользователь выберет None или Нет и активирует чекбокс `Задачи наследует свойство`
### 4.09. `Проекты` :: `Форма СРП Проектов` :: `Форма СРП Типов задач` :: Реализовать чекбокс `Представление в виде проекта`, по-умолчанию неактивен, при активации в списке дочерних проектов проекту для которого создаётся тип появляется "виртуальный" подпроект с аналогичным названием, цветовым выделением и кнопкой `Перейти` (переводит в режим Задачи где список задач отфильтрован по самому верхнему родительскому проекту), для свойств представления в окне `Форма СРП Типов задач` сделать отдельный блок снизу.
### 4.10. `Проекты` :: `Форма СРП Проектов` :: `Форма СРП Типов задач` :: `Представление в виде проекта` :: `Представление в виде проекта` в отличии от обычного `Проекта` могут иметь свойства только: каталог репозитория, связанные проекты, связанные задачи, связанная карта, связанная заметка. 

## 5. Список выработанных задач: Режим карты

### 5.01. `Проекты` :: `Список карт` :: Рядом с переключателями `Все`,`Проекты` - реализовать раздел `Макеры и метки` - данный раздел реализовать по образу `Списка задач` с фильтрацией, поиском, изменением, удалением и т.д.
### 5.02. `Проекты` + `Карты` :: `Форма СРП Проектов` :: Реализовать свойство `Связанные метки`, метки брать из режима `Карты`. 
### 5.03. `Проекты` + `Задачи` + `Карты` :: `Список задач` :: `Отображаемые свйоства` :: Штатные свойства `Связанные карты` и `Связанные метки` :: Реализовать отдельную механику для парно отображения свойств `Связанные карты` и `Связанные метки`, которые наследуются от проекта к задаче и отражаются в блоке `Дополнительно` в `Форме СРП Задач`
##### 5.03.1. Текст свойств выводится совместено через символ `/`, зеленым цветом и жирным шрифтом
##### 5.03.2. Текст выводится как кликабельная ссылка для перехода к открытию карты или к маркеру на карте
